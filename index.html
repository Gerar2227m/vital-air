Tecnología que transforma el movimiento en una solución

El problema

¿Por qué Vital-Air?

Esfuerzo constante

El Ambú es completamente manual: exige atención total y esfuerzo físico de quien lo opera.

Poco personal

En emergencias o con muchos pacientes con dificultades respiratorias, falta personal para atender cada dispositivo.

Fatiga

La operación prolongada cansa y puede afectar la precisión y constancia del procedimiento.

¿Puede la tecnología automatizar este movimiento?

Nuestra propuesta: un motor DC, controlado por Arduino y una app móvil vía Bluetooth, acciona una palanca que presiona el Ambú de forma continua y controlada. Así se busca aliviar la carga del personal y entregar aire de forma constante.

De una instrucción digital a un movimiento físico: 📱 App → 📡 Bluetooth → 🧠 Arduino → ⚡ Driver → ⚙️ Motor → 🫁 Ambú

La aplicación

El control está en tus manos: la app envía la señal al módulo Bluetooth y define la velocidad del mecanismo. La frecuencia se basa en las respiraciones humanas por minuto (entre 10 y 20 según el paciente).

Programación

Lógica de control

El Arduino lee por Bluetooth (9600 baudios) un comando y activa o detiene el motor. Con el sistema encendido, alterna ciclos de movimiento y pausa, con LED indicador de cada estado.

void loop() {
  if (Serial.available() > 0) {
    comando = Serial.read();
    switch (comando) {
      case '1': estadoSistema = 1; iniciarSecuencia(); break; // Nivel 1
      case '2': estadoSistema = 0; detenerMotorFisico(); break; // Apagar
      case '3': estadoSistema = 2; iniciarSecuencia(); break; // Nivel 2
      case '4': estadoSistema = 0; detenerMotorFisico(); break; // Apagar
    }
  }
}
Ciencia

La física de Vital-Air

⏱️ Tiempo

Duración de los ciclos. Unidad: segundo (s).

🔄 Frecuencia respiratoria

Respiraciones por minuto (rpm).

💪 Fuerza

Acción mecánica que produce la compresión. Newton (N).

⚙️ Torque

Efecto de giro del motor. Newton·metro (N·m).

🫁 Presión

Comportamiento del aire al comprimir el Ambú. Pascal (Pa).

La física permite entender cómo la energía eléctrica termina convirtiéndose en movimiento mecánico.
