# Vital-Air · Ambú automatizado

Versión visual mejorada del proyecto, preparada para trabajar en **Visual Studio Code**.

## Estructura

```text
Vital-Air-VSCode/
├── index.html
├── README.md
├── css/
│   └── style.css
└── js/
    └── script.js
```

## Mejoras incluidas

- Diseño visual más limpio y moderno.
- Jerarquía tipográfica y espaciado mejorados.
- Navegación sticky con indicador de progreso y sección activa.
- Animaciones de entrada suaves al hacer scroll.
- Feedback de `hover`, `active` y `focus` en elementos interactivos.
- Animaciones con curvas de easing personalizadas y duraciones cortas.
- Simulación visual de respiración conservada y mejor integrada.
- Tarjetas y botones con microinteracciones.
- Modo claro/oscuro con botón y memoria de la preferencia.
- Botón flotante para volver arriba.
- Mejor adaptación a celular.
- Soporte para `prefers-reduced-motion`.
- Mejoras básicas de accesibilidad (`aria`, foco visible y enlace para saltar al contenido).
- La imagen principal continúa incrustada en `index.html` como Base64 para no romper el proyecto.
- No requiere frameworks ni dependencias externas.

## Cómo abrirlo en VS Code

1. Extrae el ZIP.
2. Abre la carpeta `Vital-Air-VSCode` en VS Code.
3. Abre `index.html`.
4. Puedes usar la extensión **Live Server** y seleccionar **Open with Live Server**.

## Nota sobre las skills de diseño

La mejora toma como referencia las skills incluidas en el ZIP proporcionado: principios de diseño de interfaz, microinteracciones, easing, duración, accesibilidad de movimiento, oportunidades de animación y revisión responsive. No se copian las skills dentro de la página; sus principios se aplican directamente al HTML, CSS y JavaScript del proyecto.
